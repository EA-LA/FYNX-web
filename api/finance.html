11 / FINANCE TOOLS API

Money math,
done exactly.

Seven everyday finance calculations behind the same API key: growth, loans, CAGR, Kelly sizing, drawdown recovery, trade P/L and real return.

Results use only the numbers you send, with decimal arithmetic. They are planning arithmetic, not investment advice.

Seven endpoints.

EndpointWhat it returns
POST /v1/finance/compound-growthFuture value of a lump sum plus regular contributions, any compounding from yearly to daily, with a year-by-year schedule.
POST /v1/finance/loan-paymentMonthly payment, total interest and an optional amortisation schedule; extra payments show months saved.
POST /v1/finance/cagrCompound annual growth rate, total return and growth multiple between two values.
POST /v1/finance/kellyFull and fractional Kelly percentage, expectancy in R and break-even win rate, with an optional dollar amount.
POST /v1/finance/drawdown-recoveryGain needed to get back to a peak, the dollars to recover and how many months at a given monthly return.
POST /v1/finance/trade-pnlGross and net P/L of a closed position in any asset, return on notional and account, and R multiple.
POST /v1/finance/real-returnInflation-adjusted return (exact Fisher relation and the quick approximation) and value in today's money.

{
  "principal": "25000",

Its own key scope.

Keys need finance:calculate. Keys created with a product list keep exactly the products they had; add the scope in the workspace.

Cents that add up.

Loan schedules round each month to the cent and the final payment absorbs the remainder, so the principal column sums to the loan.

Honest warnings.

Kelly returns no_positive_edge instead of a negative bet, and flags full Kelly above 25%.
