TRUST

Data & security

What the FYNX API stores, how long it keeps it, and how keys and accounts are protected. This page describes the system as built today.

API keys

Keys are shown once, when created. FYNX stores only a SHA-256 hash of each key plus a short display prefix, so a stored key cannot be read back. Each key belongs to one workspace and one environment (test or live); the key's prefix must match its environment. Keys carry scopes that limit which products they can call. Rotation issues a new key with the same scopes and revokes the old one immediately. Revocation takes effect on the next request.

Account and tenant isolation

Every request is resolved to the key owner's workspace and environment before any data is read. One customer's accounts, rule sets and history cannot be reached with another customer's key, and test keys cannot reach live data. Disabled or unverified owner accounts cannot use their keys. These rules are covered by automated security tests that run on every change.

Abuse prevention

  • Per-second request limits per plan (10 on Free, up to 50 on Business), plus a per-minute ceiling per account.
  • Monthly allowances and customer-saved caps are hard limits.
  • Request bodies are limited to 20 KB and must be JSON; arrays are limited to documented sizes.
  • Workspace and billing actions are rate-limited per user. Key creation requires a verified email.

Operational logs never contain API keys, request bodies or results. Calculation endpoints do not fetch outside data; results depend only on what you send.

Payments

Payments are processed by Stripe. FYNX never receives or stores card numbers. Billing records (plan, subscription status, invoices) are read from Stripe.

Service providers

Google Cloud and Firebase (hosting the API, database and sign-in) and Stripe (payments). The website is hosted on Vercel.

Your controls

  • Revoke or rotate keys at any time in the workspace.
  • Limit each key to the products it needs.
  • Request deletion of your workspace data: email support@fynxfunded.com from your account email.

Report a security issue

Email support@fynxfunded.com with the subject “security report”. Please do not test against other customers’ data.
