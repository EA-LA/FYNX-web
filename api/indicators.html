06 / INDICATORS API

Indicators on
your own data.

Send a price series and get indicator values aligned to every input point, plus multi-symbol screens. Same math every time, with documented warm-up and smoothing.

Calculations use the prices you send. FYNX does not fetch market data for these routes.

Nine endpoints.

EndpointWhat it returnsExample result
sma / emaSimple and exponential moving averages (EMA seeded with the first-period SMA)SMA(3) of 1…5 → null, null, 2, 3, 4
rsiRelative strength index with Wilder smoothing57.92 on the classic 20-point Wilder series
macdMACD line, signal and histogram (12/26/9 by default)Histogram = line − signal at every point
bollingerMiddle, upper, lower bands and bandwidth (population deviation)2,4,4,4,5,5,7,9 → 5 / 9 / 1
atrAverage true range from candles, Wilder smoothing2.3 for the documented 4-candle example
stochastic%K and %D with optional %K smoothingFlat ranges return 50, never divide by zero
vwapCumulative volume-weighted average priceTypical price × volume, anchored at the first candle
screenUp to 10 conditions on the latest bar of up to 50 symbolsEURUSD matches “close above SMA(3)”; GBPUSD does not

WORKED EXAMPLE / SCREEN

Which symbols closed
above their 3-bar average?

EURUSD closed at 1.0861, above its SMA(3) of 1.08416667, so it matches. GBPUSD closed at 1.2680, below its SMA(3) of 1.26876667, so it does not.

Conditions compare close, change_percent, sma, ema or rsi against another operand or a fixed value, with <, >, crosses_above and more. Every result shows the values it compared.

POST /v1/indicators/screen
{
  "series": [
    {
      "symbol": "EURUSD",
      "values": [
        "1.0812",
        "1.0820",
        "1.0835",
        "1.0829",
        "1.0861"
      ]
    },
    {
      "symbol": "GBPUSD",
      "values": [
        "1.2710",
        "1.2702",
        "1.2695",
        "1.2688",
        "1.2680"
      ]
    }
  ],
  "conditions": [
    {
      "left": {
        "indicator": "close"
      },
      "operator": ">",
      "right": {
        "indicator": "sma",
        "period": 3
      }
    }
  ]
}

Aligned output.

Every array has one value per input point. Warm-up positions are null, never guessed.

Decimal precision.

Results are decimal strings rounded to the precision you ask for (up to 12 places).

Up to 2,000 points.

Per series, within the 20 KB request limit. Screens cover up to 50 symbols at once.
