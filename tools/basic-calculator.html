HOW TO USE THIS TOOL

Check arithmetic and percentages

Start with your inputs

Use the keypad, or focus the calculator and type numbers, operators and parentheses. Enter calculates, Escape clears and Backspace removes the last character.

The calculation or concept

Use standard order of operations: parentheses, multiplication and division, then addition and subtraction. A postfix percent divides its value by 100.

Worked example

200 × 5% = 10. For a 5% increase on 200, calculate 200 × (1 + 5%) = 210. By contrast, 200 + 5% adds 0.05 and gives 200.05.

Hypothetical example, not a current quote.
Assumptions and limitations

Results use decimal approximations and show up to 14 significant digits. Use a dedicated financial tool when exact currency rounding matters. A percentage is interpreted as a fraction; division by zero is rejected.
