Generate trading-platform source from your latest completed backtest settings. Fynx Accounts can connect supported accounts read-only. This website does not place trades.

Set up in MetaTrader 5
  1. Open MT5 and sign in to your challenge or demo account in MT5.
  2. Choose File › Open Data Folder › MQL5 › Experts and save the .mq5 file there.
  3. Open it in MetaEditor, compile, and review any compiler messages.
  4. Test in the Strategy Tester and on a demo/free trial first.
  5. Attach to the tested symbol and timeframe and enable Algo Trading.
For MT4 use MQL4/Experts. For cTrader create a cBot in Automate and paste the generated C#. Platform source must be compiled and validated in that platform. Broker feeds, spread, execution and session boundaries can differ from this research data.
