Building a Core-Satellite Plan

Balance broad exposure with tactical themes.

FYNX learning guide • Educational example •

Define the role of each holding

A core-satellite framework separates broad exposure from smaller, more specialized positions. The terms describe portfolio roles, not universally correct percentages. A useful plan states the objective, time horizon and loss tolerance before selecting funds. A specialized fund can overlap heavily with a broad core despite having a different name.

Make the rules observable

Specify how allocation drift will be measured and when it will be reviewed. Account for fees, taxes and the possibility that several satellites react to the same factor. A portfolio organized into many tickers can still be concentrated in a handful of companies or one industry. Rebalancing rules are easier to evaluate when written before a market move.

WORKED EXAMPLE

Put the idea into numbers

In a hypothetical $10,000 portfolio, an 80% broad-market allocation is $8,000 and a 20% specialized allocation is $2,000. If both own the same largest companies, the combined concentration exceeds what the two labels suggest.
